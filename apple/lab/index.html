Motion lab

Every technique the animation skills teach, isolated and interactive, with the exact values each recipe specifies. Nothing here is decoration for its own sake — the point is to show what each tool is for, and where it stops being appropriate.

Easing: built-in vs custom

The single highest-leverage change in most codebases. Built-in easings are too weak — they lack the early acceleration that makes motion feel intentional. Both bars below run for the same 600ms.

ease-out
cubic-bezier(0.23, 1, 0.32, 1)
--ease-out: cubic-bezier(0.23, 1, 0.32, 1)

Spring parameters

Apple's two-value parameterisation — a damping ratio and a response time — instead of mass, stiffness and damping. Damping 1.0 is critically damped: no overshoot. Add bounce only when a gesture carried momentum into the motion.

{ type: "spring", bounce: 0, duration: 0.4 }

Stagger

30–80ms between items. Longer reads as slow; simultaneous reads as a jump cut. Stagger is decorative, so it must never block interaction while it plays.

delay: stagger(0.06)

Tab indicator, clipped

The list is rendered twice. The copy is styled as the active state and clipped to the active tab, so the text and background change in perfect sync. Timing two separate colour transitions can never achieve this.

clip-path: inset(0 60% 0 20%) · 250ms var(--ease-in-out)

Squash & stretch

Anticipation, then deformation under load, then follow-through. Weight is communicated by how a thing deforms, not by how far it travels.

anticipate −8px → fall → scale(1.25, 0.75) → settle

Number ticker

Tabular figures are not optional. Without them every digit change shifts the layout and the eye follows the jitter instead of the value.

0tabular-nums
0proportional — watch it shuffle
font-variant-numeric: tabular-nums

3D flip

rotateY with transform-style: preserve-3d and a perspective on the parent. A lower perspective value exaggerates the depth, as though the viewer were closer.

Ask
Answer
perspective: 800px · rotateY(180deg) · preserve-3d

Typewriter

Character-by-character reveal. Legitimate for a first-run moment; a liability anywhere people need to read the same string twice. Respects reduced motion by appearing whole.

~28ms per character, cursor blink 1s steps(2)

Drag to dismiss

Velocity decides, not distance. A quick flick should be enough even if the card barely moved — requiring a threshold makes the gesture feel unresponsive.

Flick me sideways

velocity: —

Math.abs(distance) / elapsedMs > 0.11 → dismiss

WAAPI

element.animate() — JavaScript control with CSS performance. Hardware accelerated, interruptible, and no library required.

el.animate([{clipPath:'inset(0 0 100% 0)'},{clipPath:'inset(0 0 0 0)'}], …)

@starting-style

Entry animation with no JavaScript and no mounted flag. The browser interpolates from the starting style the first time the element is rendered.

@starting-style { opacity: 0; transform: scale(0.95) }

Motion blur

For very fast motion, a subtle blur encodes speed better than a hard sharp streak. Keep it under 20px — heavy blur is expensive, especially in Safari.

filter: blur(0 → 3px → 0) across the travel
